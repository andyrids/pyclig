# The public API of pyclig, frozen at 1.0 - checked by tests/test_api.py.
#
# Format: one `key value` line per entry, sorted. The value is
#   (...) -> ...     a callable's signature, as tests/test_api.py renders it
#   class (...)      a class & its own `__init__`; `enum` for an enumeration
#   property (...)   a property, `settable` when it has a setter
#   = ...            a type alias, or a class attribute's value
#   module           a submodule
#   <int>            an `ExitCode` member's value
# and a `rule:<ID>` line, with no value, is a rule ID the conformance kit emits.
#
# Covered: the `__all__` names of pyclig, pyclig.options, pyclig.paths &
# pyclig.testing, the `ExitCode` members, the public members that Context,
# Command, Group, GlobalOption, Config & testing.Finding define themselves, and
# the kit's rule IDs.
#
# Freeze: this file is edited by hand, never regenerated, so that every change
# to the API is a deliberate diff. The test names each difference:
#   removed - breaking, needs 2.0
#   changed - breaking unless it only adds an optional parameter or reorders
#             keyword-only ones
#   added   - add the line deliberately
